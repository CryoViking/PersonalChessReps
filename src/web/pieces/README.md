Colin M.L. Burnett (Wikimedia Commons user Cburnett), downloaded from
Wikimedia Commons (File: Chess_klt45.svg and siblings, revision of
11 September 2022). They are offered under GFDL 1.2+, CC BY-SA 3.0,
